Nama Projek: Adventure Camp Sistem Penyewaan Peralatan Camping
DESKRIPSI PROJEK
Adventure Camp merupakan program berbasis console yang dibuat menggunakan bahasa pemrograman C untuk membantu proses penyewaan peralatan camping.
Program ini dapat menampilkan daftar peralatan, menghitung biaya sewa berdasarkan jumlah unit dan lama penyewaan, memberikan diskon otomatis, menampilkan struk, serta mencatat riwayat transaksi selama program berjalan.
